for state in states:
    candidates = {
        origin: scores[origin]
        * transition[origin][state]
        for origin in states
    }
    best = max(candidates,
               key=candidates.get)
    next_scores[state] = (
        candidates[best]
        * emission[state][observation]
    )
    previous[state] = best

12 KESIMPULAN

Satu jalur.
Tiga pelajaran.

01

Optimal secara global.

Viterbi memilih urutan paling mungkin untuk seluruh observasi, bukan cuaca tiap hari secara terpisah.

02

Efisien secara komputasi.

Skor terbaik dan pendahulu menggantikan enumerasi seluruh jalur. Log-space menjaga stabilitas numerik.

03

Bergantung pada model.

Perubahan transisi atau emisi mengubah hasil. Tidak ada label cuaca nyata untuk menilai akurasi.

Ruang lingkup

Satu pola sintetis, tiga state, satu lingkungan pengukuran. Interaksi alpha dan beta tidak diuji.
